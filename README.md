# HastellColor

オイルパステルと水彩色鉛筆の描画モデルを Haskell で作るプロジェクトです。
現在は GUI を使わず、仮想紙にストロークを描いて PPM 画像を生成できます。
将来は iPadOS の Swift / Metal と連携します。

## 構成

- `src/HastellColor/`: 描画モデルのライブラリ。
  - `Color.hs`: RGB、黒・白、成分の範囲制限、RGB 成分の補間。
  - `Paper.hs`: 紙目、顔料の付着量、堆積を反映した接触面の計算。
  - `Stroke.hs`: 座標・筆圧・傾き・方位を持つサンプルと、その補間。
  - `Brush/OilPastel.hs`: 紙目と堆積面への付着、傾きによる楕円形の接触、消費・摩耗の状態遷移。
  - `Image/PPM.hs`: 紙を PPM（P3、8ビット RGB）文字列に変換する純粋関数。
- `app/Main.hs`: 仮想ストロークを描き、画像をファイルに保存する入口。
- `app/Scenes.hs`: 単線デモと、条件を固定した比較用ストローク。
- `app/Comparison.hs`: 比較画像の配置とラベル。画材の計算はライブラリを利用します。
- `test/Main.hs`: 色、紙目、筆圧、重ね塗り、顔料残量、境界、PPM 形式のテスト。

`app` と `test` は同じライブラリに依存します。描画モデルを `src` に置き、
ファイル入出力や実行用の処理は `app` に置きます。

## 実行

プロジェクトのルートで実行します。

```sh
cabal build all
cabal run HastellColor
cabal test all --test-show-details=direct
cabal check
```

`cabal run HastellColor` は、カレントディレクトリの `hastellcolor.ppm` に保存します。
出力先を指定する場合は `cabal run HastellColor -- sample.ppm` を使います。
同じ出力先がある場合は上書きします。

デモは 256×256 の白い紙に、`(50, 100)` から `(200, 140)` へ朱色の線を描きます。
筆圧は 0.2 から 0.95 へ増加します。紙の粗さ、乱数シード、色、半径、ストロークは
`app/Scenes.hs` で変更できます。既定の生成画像は Git の管理対象から除外しています。

## 比較画像

```sh
cabal run HastellColor -- --comparison
cabal run HastellColor -- --comparison sample-comparison.ppm
```

既定の出力先は `hastellcolor-comparison.ppm` です。4行×3列の比較画像を生成します。
各パネルは 256×256 の紙を等倍で表示し、条件名は紙の外側に英語で描きます。

| 行 | 左 → 中央 → 右 | 固定する条件 |
|---|---|---|
| 筆圧 | 0.2 → 0.5 → 0.9 | 粗さ0.9、1回塗り |
| 紙の粗さ | 0 → 0.5 → 0.9 | 筆圧0.5、1回塗り |
| 重ね塗り | 1回 → 2回 → 10回 | 筆圧0.5、粗さ0.9 |
| 傾き | 90° → 60° → 30° | 筆圧0.5、粗さ0.9、方位90°、1回塗り |

全パネルで色、軌跡、紙目のシード42、初期半径14を共通にしています。
比較用の筆圧・傾き・方位は線全体で一定です。最初の3行は垂直に立てた状態です。
各パネルは未使用の紙と新品のパステルから始め、
重ね塗りの途中では紙・顔料残量・摩耗を引き継ぎます。
そのため塗る回数による濃さの変化に加え、摩耗による半径の変化も現れます。

筆圧行の中央、粗さ行の右、重ね塗り行の左、傾き行の左は同じ基準条件です。
出力は再現可能なので、モデルを変更する前後や実物サンプルとの比較に使えます。
条件は `app/Scenes.hs` の `comparisonCases` にまとめています。

## 傾きと向きの入力

内部の角度はラジアンです。画像内のラベルは度で表示します。

- `sampleAltitude`: 紙面からの角度。`pi / 2` が垂直、`pi / 6` が30°、`0` が水平です。
- `sampleAzimuth`: 紙面上の向き。右向きの +X を0、下向きの +Y を `pi / 2` とします。
  楕円の長軸がこの向きになります。垂直のときは向きによる違いがありません。

```haskell
-- 垂直に立てたサンプル
uprightSample (Point 50 100) 0.5

-- 紙面から30°に寝かせ、長軸を下向きにしたサンプル
(uprightSample (Point 50 100) 0.5)
  { sampleAltitude = pi / 6
  , sampleAzimuth = pi / 2
  }
```

筆圧と傾きは線形補間し、方位は短い回転方向で補間します。
傾きを小さくすると接触する楕円の長軸・短軸が広がります。水平でも大きさは有限です。
角度と接触半径の関係は実測に基づくものではなく、調整用の近似です。

言語設定は `GHC2021`、依存パッケージは `base ^>=4.21.0.0` です。
GHC 9.12.4 / cabal-install 3.16.1.0 で動作を確認しています。

## 現在のモデルと次の段階

`makePaper` と `drawStroke` は純粋関数です。`drawStroke` は更新された紙と
パステルの状態を返します。入力の不正な寸法・数値範囲などは `Either String` で返します。

座標とブラシ半径の単位は紙のセルです。原点を左上に置き、右方向を X、
下方向を Y とします。紙のセルは行ごとに左から右へ並べたリストで保持します。
筆圧、紙の粗さ・高さ、顔料付着量、パステルの顔料供給量・摩耗は 0〜1 とします。
型のコンストラクタは公開しています。直接 `Paper` を作る場合は、セル数と各値の範囲を
守る必要があります。通常は `makePaper` で生成します。

描画は、線分に沿って動く楕円形の接触範囲と、その場所の筆圧・接触面の高さで計算します。
弱い筆圧では凸部を中心に、強い筆圧では谷にも顔料が付着します。空のストロークと
筆圧ゼロは何も描かず、1点の入力は点を描き、紙からはみ出した部分は描画しません。

接触面は、紙の元の高さに、そのセルの顔料と周囲8セルの顔料の影響を加えて求めます。
周囲の堆積によって細かい谷をまたぐ効果を近似し、重ね塗りで接触できる範囲が広がります。
元の紙目は変更せず、接触面の計算だけでは顔料を増減・移動させません。
周囲の参照は紙の端で止め、次の行への回り込みも起こしません。

現段階の近似と制限:

- 色は RGB 成分の補間です。顔料の吸収・散乱を再現する混色モデルは未実装です。
- 付着量はセルごとの 0〜1 の量で、最大量に近づくほど追加の付着が減ります。
- 接触面の高さも0〜1です。これは被覆量を使った近似で、実際の層の厚さや塑性変形の
  シミュレーションではありません。接触面は各ストローク開始時の紙から計算します。
- `pastelCapacity` は新品のパステルが満たせるセル数に相当する顔料量です。
  残量が不足するとストローク全体の付着量を比例して減らします。
- 消費量に応じて摩耗が増え、次のストロークの接触半径が少し広がる簡易モデルです。
  消費と摩耗はストロークごとに更新し、ストローク途中の変化はまだ扱いません。
- 同じストローク内では各セルへの最大接触量を使います。筆圧・傾き・向きが一定の直線では、
  サンプル点を増やしても付着が変わらないことをテストしています。
  入力値が変化する線分では、その付近の楕円形状で接触位置を近似するため、
  急な変化に対する精度や入力点の間隔への依存は今後の検証対象です。
  同じ呼び出し内で折り返しても重ね塗りにはならず、
  重ね塗りは `drawStroke` を再度呼び出して行います。
- 現在は全セルを走査する CPU の参照実装です。リアルタイム描画用の最適化は今後行います。
- 速度・こすれ、水彩色鉛筆の水分・拡散・乾燥、Swift / Metal 連携は未実装です。

次は実物の筆圧・傾き・重ね塗りサンプルと比べ、紙目・接触形状・付着量を調整します。
